## Відповіді на контрольні запитання

### 1. Що таке CSS Grid Layout і для яких завдань веброзробки він використовується?
**CSS Grid Layout** — це двовимірна система компонування (layout) у CSS, яка дозволяє одночасно керувати розміщенням елементів по рядках (горизонталі) та колонках (вертикалі). Використовується для побудови загальної архітектури сторінок (header, sidebar, main, footer), складних фотогалерей, сіток карток різного розміру, дашбордів та адаптивних макетів без потреби у додаткових обгортках чи хаках із `float`/`position`.

### 2. У чому полягають основні відмінності між CSS Grid Layout та Flexbox?
- **Вимірність:** Flexbox є *одновимірним* (працює або з рядком, або з колонкою за раз), тоді як CSS Grid є *двовимірним* (одночасно контролює і рядки, і колонки).
- **Підхід до розміщення:** Flexbox працює «від контенту» (*content-first*) — розміри елементів визначаються їхнім вмістом; Grid працює «від макета» (*layout-first*) — спочатку задається структура сітки, у комірки якої вкладаються елементи.
- **Накладання елементів:** У Grid елементи можуть легко перекривати один одного в межах спільних клітинок без `position: absolute`.

### 3. Як створити grid-контейнер? Чим відрізняються значення `grid` та `inline-grid` властивості `display`?
Grid-контейнер створюється заданням `display: grid` або `display: inline-grid` батьківському елементу.
- `display: grid` створює **блочний** grid-контейнер, який займає всю доступну ширину батьківського контейнера та починається з нового рядка.
- `display: inline-grid` створює **рядковий** grid-контейнер, ширина якого підлаштовується під його вміст, і він розташовується в один рядок із сусідніми рядковими елементами.

### 4. Що таке grid-контейнер, grid-елемент, grid-лінія, grid-трек, grid-комірка та grid-область?
- **Grid-контейнер (grid container):** елемент із `display: grid` / `inline-grid`, у якому створюється сітка.
- **Grid-елемент (grid item):** прямий дочірній елемент grid-контейнера.
- **Grid-лінія (grid line):** роздільна лінія (вертикальна або горизонтальна), що утворює структуру сітки; нумерується з `1` (або `-1` з кінця).
- **Grid-трек (grid track):** простір між двома сусідніми grid-лініями (тобто один рядок або одна колонка).
- **Grid-комірка (grid cell):** найменша одиниця сітки на перетині одного рядка та однієї колонки.
- **Grid-область (grid area):** прямокутна ділянка з однієї або кількох суміжних grid-комірок, обмежена чотирма grid-лініями.

### 5. Для чого використовуються властивості `grid-template-columns` та `grid-template-rows`?
Вони визначають кількість і розміри колонок (`grid-template-columns`) та рядків (`grid-template-rows`) у явній сітці (explicit grid). Кожне вказане значення задає розмір відповідного треку (у `px`, `%`, `fr`, `auto`, `minmax()` тощо).

### 6. Що таке одиниця вимірювання `fr` і як вона використовується для розподілу доступного простору в CSS Grid?
`fr` (*fraction* — частка) представляє частку вільного простору в grid-контейнері після обчислення фіксованих розмірів (`px`, `rem`) та проміжків (`gap`). Наприклад, `grid-template-columns: 200px 1fr 2fr` виділить 200px першій колонці, а решту ширини поділить у пропорції 1:2 між другою і третьою колонками.

### 7. Для чого призначені функції `repeat()`, `minmax()` та `fit-content()` у CSS Grid?
- `repeat(кількість, шаблон)` — скорочує запис повторюваних треків (наприклад, `repeat(5, 1fr)`).
- `minmax(min, max)` — задає діапазон розмірів треку: не менше `min` і не більше `max` (наприклад, `minmax(250px, 1fr)`).
- `fit-content(max)` — стискає трек за розміром вмісту, але обмежує його максимальне розширення вказаним значенням `max`.

### 8. У чому полягає різниця між ключовими словами `auto-fill` та `auto-fit` під час використання функції `repeat()`?
Обидва автоматично розміщують максимально можливу кількість колонок заданої мінімальної ширини в рядку, але поводяться по-різному, коли елементів менше, ніж вміщується в рядок:
- `auto-fill` **зберігає** порожні треки в кінці рядка (вони продовжують займати місце).
- `auto-fit` **згортає** порожні треки до `0px` і розтягує наявні елементи на всю доступну ширину контейнера.

### 9. Як працює властивість `gap` та чим відрізняються `row-gap` і `column-gap`?
Властивість `gap` задає інтервали (жолоби) виключно **між** треками сітки (не додаючи відступів по зовнішніх краях контейнера).
- `row-gap` задає відстань між рядками.
- `column-gap` задає відстань між колонками.
- `gap: <row-gap> <column-gap>` є скороченим записом для обох властивостей.

### 10. Для чого використовуються властивості `grid-column` та `grid-row`? Як за їх допомогою керувати розташуванням і розмірами grid-елементів?
Це скорочені властивості (`grid-column-start / grid-column-end` та `grid-row-start / grid-row-end`), які визначають, між якими лініями сітки розташовується елемент і скільки колонок/рядків він охоплює. Наприклад:
- `grid-column: 1 / 3` або `grid-column: span 2` — розтягує елемент на 2 колонки.
- `grid-column: 1 / -1` — розтягує елемент на всю ширину сітки від першої до останньої лінії.

### 11. Що таке іменовані grid-області та як використовувати властивості `grid-template-areas` і `grid-area`?
Іменовані grid-області дозволяють візуально описати структуру макета текстовою матрицею:
1. У контейнері через `grid-template-areas` задаються назви областей для кожного рядка і колонки (крапка `.` позначає порожню клітинку).
2. Дочірнім елементам призначається відповідне ім'я через `grid-area: назва_області` (без лапок).

### 12. Як працюють властивості `justify-items`, `align-items`, `justify-content` та `align-content` у grid-контейнері?
- `justify-items` — вирівнює вміст grid-елементів уздовж **рядкової (горизонтальної)** осі всередині їхніх комірок (`start`, `end`, `center`, `stretch`).
- `align-items` — вирівнює вміст grid-елементів уздовж **блочної (вертикальної)** осі всередині їхніх комірок.
- `justify-content` — вирівнює **всю сітку треків** по горизонталі всередині контейнера (коли сумарна ширина треків менша за ширину контейнера).
- `align-content` — вирівнює **всю сітку треків** по вертикалі всередині контейнера.

### 13. У чому полягає різниця між явною (explicit grid) та неявною (implicit grid) сітками? Для чого призначені властивості `grid-auto-rows` і `grid-auto-columns`?
- **Явна сітка (explicit grid)** створюється розробником через `grid-template-columns`, `grid-template-rows` та `grid-template-areas`.
- **Неявна сітка (implicit grid)** генерується браузером автоматично, коли елементів більше, ніж комірок у явній сітці, або коли елемент розміщено поза її межами.
- `grid-auto-rows` та `grid-auto-columns` задають розміри автоматично створених неявних рядків і колонок.

### 14. Як працює властивість `grid-auto-flow` та як вона впливає на автоматичне розміщення елементів у сітці?
`grid-auto-flow` керує алгоритмом авторозміщення елементів, для яких не задано явних координат:
- `row` (за замовчуванням) — заповнює сітку по рядках зліва направо.
- `column` — заповнює сітку по колонках зверху вниз.
- Ключове слово `dense` (`row dense` або `column dense`) — дозволяє алгоритму повертатися назад і заповнювати порожні «дірки» в сітці меншими елементами, що йдуть далі в DOM.

### 15. Як створити адаптивний макет за допомогою CSS Grid із використанням `repeat()`, `minmax()`, `auto-fit` та медіазапитів?
- **Без медіазапитів (fluid grid):** `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));` — колонки автоматично переносяться на новий рядок і рівномірно розтягуються при зміні ширини екрана.
- **З медіазапитами (`@media`):** задається базова мобільна сітка (`1fr` за принципом *mobile-first*), а на контрольних точках (`576px`, `768px`, `992px` тощо) змінюються `grid-template-columns`, `grid-template-areas` або `grid-column`/`grid-row` для перебудови структури під планшети та десктопи.
